# LoRa Rain Sensor

Proyecto personal para desarrollar un sensor de lluvia con comunicación LoRa.

El proyecto está en una fase inicial. El firmware, el hardware y su documentación se irán incorporando a este repositorio a medida que avance el desarrollo.

## Licencia

La intención es permitir el uso, la modificación y la compartición del proyecto para fines no comerciales. Las licencias concretas para el firmware, el hardware y la documentación están pendientes de definir. Hasta entonces, este archivo no concede una licencia de uso general sobre el contenido del repositorio.
